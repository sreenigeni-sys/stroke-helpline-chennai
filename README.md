# Stroke Helpline Chennai

A test build of a Chennai stroke check and hospital locator.

- Opens with a BEFAST check, then a last-seen-well time.
- Shows a 4.5-hour and 9-hour countdown from that time.
- Lists stroke-ready and comprehensive centres, nearest first, with a map.

This is a locator for testing. It does not diagnose stroke and it does not replace calling for an ambulance.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:8080

Government hospitals dial 108. Apollo hospitals dial 1066. Other hospitals dial the emergency number published on their site.
